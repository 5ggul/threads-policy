개인정보처리방침

본 앱은 Threads API 연동을 위해 필요한 최소한의 계정 식별 정보와 액세스 토큰 정보를 처리할 수 있습니다.

1. 수집 정보

  • Threads 사용자 ID
  • Threads 액세스 토큰
  • 사용자가 직접 입력한 게시 콘텐츠

2. 이용 목적

  • Threads 게시물 작성 및 예약 발행
  • API 연결 상태 확인
  • 오류 로그 확인

3. 보관 및 삭제

사용자 요청 시 저장된 설정 및 관련 데이터는 삭제할 수 있습니다. 삭제 요청은 데이터 삭제 안내 페이지를 참고해 주세요.

4. 문의

문의가 필요한 경우 앱 운영자에게 직접 연락해 주세요.
